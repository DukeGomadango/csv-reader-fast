A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` exports `run({text, header})`, which returns the same `{columns, rows, errors}` as the reference for every input, including broken CSV. It reads the text in one pass over char codes and slices fields out of it instead of building each field a character at a time. `main.ts` is the harness driver.

## Run it

```sh
node main.ts   # reads /input/cases.json, writes /output/answers.json (MAKEFUN_INPUT_DIR / MAKEFUN_OUTPUT_DIR override)
```
